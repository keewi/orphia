NewInitial prompt
"Pick a letter to start guessing!" in muted italic. Replaces empty space before first guess. Disappears the moment the first key is pressed.
2
ChangedGrid row layout — 10 per row
Max 10 per row (letter tiles + punct tiles + word-space gaps). "You're the One That I Want" → Row 1: YOU'RE·THE (10), Row 2: ONE·THAT (8), Row 3: I·WANT (6). Words pack greedily; if the next word + its gap would exceed 10, it wraps.
3
ChangedPunctuation tile style
Apostrophes and other punct characters render as a filled tile — var(--key-unused) background, var(--border) outline, ink-coloured character. Same size as letter tiles. Never changes state (no gold reveal, no flash) — it's pre-filled information, not a guessable letter.
